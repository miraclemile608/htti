# HTTI · 虚界投影

静态恐怖互动问卷：32 道五级量表题、4 段对话、两本独立的账与 16 种结局配图。用于娱乐，不是经过验证的心理测量工具。

## 本地预览

在项目目录打开 PowerShell：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

保持终端运行，浏览器打开 http://127.0.0.1:8765/ 。若 python 不可用，改用 py。按 Ctrl+C 停止服务。若端口已占用，先尝试直接打开页面，或将端口改为 8766。

也可以直接双击 index.html 用 file:// 打开，问卷、图片与合成音仍可使用。完整恐怖音效包含需要通过 HTTP 加载的本地采样，请优先使用上面的本地预览方式。进度存储失败时自动降级（不续答，其余照常）。

## 本次改进

- 题目从「四选一」改成「一句陈述 + 五级量表」：完全不符合 / 比较不符合 / 不确定 / 比较符合 / 完全符合，记 0–4 分。每维 8 题，正问与反向题各 4 道，反向题按 4−档位翻转；代码里用 `dir` 标着，改题时不会漏。
- 计分改成连续分：每维 0–32，`ratio = 分 / 32`，大于 16 落开极，小于 16 落闭极。恰好 16 分的平持不再默认归闭极，改由作答指纹（按题目 ID 排序后的答案串算 FNV-1a）决定，结果页照实以「≈ 持平」和虚线标出，不隐藏。全选同一档时四维恒为 16 分，落在码表里五个互相不同的码，不会靠一档到底拿到最开或最闭的那一型；结果页照常出档案，不为这份答案加任何标注或提示，类型名、配图、结果图都只写结果本身。
- 两本账拆开：里层 = 四扇门（门/频/权/痕）的平均开放度；表层只看「不会被吓到、不入戏、不留痕」三项，不含门。所以两账不再共用同一个 O，相加也不是固定值——只有门开是 125，只有频率开是 92，随机作答落在 86–115 之间（均值 100）。
- 默认开启环境音，首次点击继续后启动：CC0 恐怖环境音循环叠加合成低频、失谐泛音、耳语、敲击和心跳，随答题进度增加压迫感。突脸使用三层混合的短促采样和低频冲击，瞬间压低背景，突出声画反差。素材全部随项目分发，[来源、授权与处理记录](assets/audio/README.md)可查。M 键或顶部按钮静音；页面进入后台时暂停并取消突发声。素材加载失败时回退到合成音，浏览器不支持音频时可继续答题。
- 主突脸由第 11–32 题中的随机一题触发。作答会先记住所选档位，等主突脸结束后再换题。切后台时会立即清理画面和声音，尚未展示的主突脸回前台后可补播。存档会保留已选题位和展示状态，续答时沿用同一轮的触发记录。
- 氛围事件从第 11 题起随机出现，至少间隔 3 题和 16 秒，每轮最多 5 次。主突脸使用独立的 `assets/haunt-face.webp`，结局图集按类型取格。
- 提供低刺激模式和突发效果开关；尊重系统减少动态效果偏好——但**减少动态不是删掉突脸**，见下表。
- 左下角是对讲机通联记录（`CH-07 / 救援频道`）：一支探险小队进入 B2 层遭遇「她」，9 条记录随答题进度逐条解锁，从例行报到一路掉到只剩电流。每条按 40–60ms 一个字打出来（后面还排着行时提速到 30ms，不拖住换题节奏），打完停 0.6 秒再接下一行；减少动态或低刺激下整行直接写好，不做逐字。恐怖事件落下时对讲机里会多一行 `[noise]` 杂音、面板抖一下；低刺激与减少动态下不插杂音也不抖。面板本身对读屏隐藏（`aria-hidden`），只有最后一条「只剩电流」单独播报一次。浅色阶段整块隐藏，不抢戏。
- 「找到你了」先显示平静肖像。点击「查看你的虚界投影」后，三张同机位肖像在约 2.4 秒内依次淡入，由平静变为半笑，再变成完整的诡异微笑。随后是 1.4 秒撕裂、3 秒黑场「欢迎加入我们」和结果档案。减少动态模式用静止肖像和文字，低刺激模式保持平静肖像。演出前那句「接下来会显示一张静止的微笑画面……」的预告窗只在完整强度下出现：低刺激与减少动态下整个不渲染，连文本都不留，读屏也不会播报这句（其余播报照旧）。

### 恐怖事件在三种偏好下的表现

| 场景 | 突脸 / 黑场 | 声音 | 说明 |
|---|---|---|---|
| 默认 | 那一次突脸：face 650ms、黑场 950ms（仅当指定题落在黑屏段）；氛围事件 1600ms | 有 | 每轮一次主突脸，进题触发，播完后自动继续已经提交的答案 |
| 系统「减少动态效果」 | 先 1.6 秒文字预告，再显示静止画面（突脸 1500ms、黑场 1700ms） | 有 | 快速作答也会等预告和静止画面播完 |
| 用户主动关掉突发效果 / 低刺激模式 | 关闭（用户自己的选择，默认是开着的） | 关 | 顶部按钮随时可开回来 |

闪烁层（第 5 阶段）在两处都仍然关闭；减少动态下不再有横扫阴影和缩放动画，但画面本身不会缺席。
- 16 种结局各有一幅生成插画，使用本地 WebP 图集。具体分数影响明暗、对比度和侵蚀层。
- 结果编号作为纯文本显示（四位随机数 0000–9999，结果生成时抽一次），不上传；「找到你了」显示「型名-编号1234」，档案页宿主行与结果图同步用这个编号。开局不再要求输入名字或 ID，开始按钮固定为小写 `sink`，永远可用。支持 1–5 数字键答题、← 返回上一题、查看结果图（可保存或分享）和重新测试。
- 结果页底部是「查看结果图」：点一下先弹出全屏预览，居中显示一张用 canvas 现场画的 1080×1600 竖版 PNG（高分屏按 devicePixelRatio 放大 2 倍再缩回），不直接下载。预览下方固定两个按钮「保存图片」与「分享」：「保存图片」才真正下载，文件名形如 `HTTI-闪影-编号7777.png`；「分享」在任何浏览器都显示、不依赖 Web Share，点开一行六个平台——微信、QQ、QQ 空间、哔哩哔哩、系统分享、复制图片。QQ 与 QQ 空间在新窗口打开各自的官方分享页，参数只有页面链接与文字摘要（`url` / `title` / `summary` 逐个编码）。微信与哔哩哔哩没有可用的网页分享接口，做成「复制图片 + 复制链接」：图片走 `ClipboardItem`（`image/png`，同一次写入里再附一段带链接的文字，可以直接粘进桌面微信/QQ 输入框），拿不到 `ClipboardItem` 时退化成只复制链接并提示；系统分享只在 `navigator.canShare({files:[file]})` 为真时可用并带 PNG 文件，复制图片只在 `navigator.clipboard.write` 与 `ClipboardItem` 都在时可用；不支持的项置灰、在说明里写原因，但不会从列表里消失。外部平台拿不到本地 PNG，所以只带链接和摘要，图片要靠「复制图片」或先保存——这句也写在弹层底部。`file://` 打开时链接回退成线上地址 `https://miraclemile608.github.io/htii/`，不会把本机路径发出去。右上角 ×、Esc、点遮罩空白处都能关闭；打开时焦点进入弹层，关闭后回到「查看结果图」，Tab 在关闭/保存/分享与展开后的平台项之间循环；关闭时收起平台行、释放 blob URL。减少动态下不加弹层过渡。图上依次是站名与档案编号、型名与四字母代码、该型在结局图集里的那一格配图（右上角 330px 见方、整体略往上收，不与型名、代码格、四维条形和「同化接口」那行抢位置，按 `Object.keys(TYPES)` 的顺序取 4×4 图集的行列，亮度与对比度跟页面用同一套 `--art-light`/`--art-contrast` 公式）、四个维度 0–32 分与条形（标着 16 分中位线）、表层/里层两本账、该型现有的那句判词，页脚是日期、「HTTI · 娱乐向概念框架，非心理测量」和作者 miracle-mile。配图先 `Image` 载入再画：加载失败照常出图，空位写「配图未载入」并轻提示一句；用 `file://` 直接打开时本地图会把画布标记为污染、`toBlob` 抛 SecurityError，这时重画一张不带配图的照样出预览（提示「这张图里没有形象」），仍然失败才退回文字版。绘制只用原生 canvas 和系统字体栈，不请求任何外部字体或图片（配图就是页面自己的结局图集）；浏览器给不出 2d 上下文时不弹空预览，退回复制文字版并提示。
- 进度存在 sessionStorage 里（键名 `htti.session.v1`）：同一个会话里刷新或误关标签页再回来，首页会问要不要接着上次那一题。只覆盖本次会话，不做跨天续答，关掉浏览器就不保留；黑屏期间锁住答题，漏答的题会被送回原题而不是按 0 分算。
- 顺手修的无障碍问题：小字提到 10–11px 一档、低对比色压深、所有屏可聚焦、警告弹窗有焦点陷阱和 Esc、「她在线」在窄屏不再整块消失（改成底部单行 ticker，同一位置只留最新一条，历史行不会叠在一起，长句用省略号截断；拉宽窗口后恢复整段记录）、结果出现时向读屏播报。
- 救援频道不压正文：它是 `pointer-events:none` 的装饰层，宽屏在左下角、宽度按居中 760px 正文栏两侧的留白自动收窄（`clamp(150px, calc((100vw - 760px)/2 - 40px), 246px)`，1240–1500px 区间也不会伸进正文），≤1240px 切成底部通栏单行；答题、表层封存、找到你了、档案、加载五屏都按 `--presence-pad`（宽屏 96px、窄屏 54px）在底部留出同样高的空位，所以最后一行文字、提示与按钮滚到底也落在面板上方。

更多情境旨在改善区分度。10 万次随机作答下 16 型各占 6.17%–6.34%（见下），但真实玩家分布仍需后续采样验证。

## 浏览器人工验收

1. 打开首页，确认默认音效选项勾选；点击继续后播放环境音。关闭、开启及 M 键切换有效。
2. 首页确认没有名字/ID 输入，开始按钮固定为小写 `sink`、直接可用；每道正式题是一句陈述加五个刻度，鼠标和 1–5 数字键都能选，快速连点只记一次，返回后能看到原来选的那一档。
3. 完成 32 题及 4 段对话，确认前期较轻、后期逐步加深。后期每题可停留 8–10 秒观察随机事件，单轮没有遇到某种事件属正常。
4. 答题过程中切到其它标签页，确认暂停声音；返回后恢复。关闭突发效果后不再随机突脸。第 6 题后的黑屏期间试着按数字键，应该完全没反应。
5. 完成结局揭示，确认肖像从平静到半笑再到完整微笑，连点按钮也会完整播完。检查档案配图、类型、分数、四维条形图；点「查看结果图」，确认先弹出全屏预览而不会直接下载，预览里是一张竖版档案卡（型名、代码、四维分数与 16 分中位线、两本账、判词、日期与作者）。点「保存图片」确认下载 PNG，文件名形如 `HTTI-闪影-编号7777.png`。点「分享」展开平台行：QQ、QQ 空间会在新窗口打开官方分享页（只带链接与摘要，参数不乱码）；微信、哔哩哔哩会尝试复制图片与链接并提示去粘贴，浏览器不支持 `ClipboardItem` 时只复制链接；「系统分享」只在浏览器能分享图片文件时可用，「复制图片」只在支持剪贴板图片时可用，其余项置灰并写明原因、不会消失。分别用 ×、Esc、点遮罩空白处关闭（平台行展开时也一样），确认平台行收起、焦点回到「查看结果图」。
6. 点「再测一次」确认进度归零；中途关掉标签页再打开，确认首页出现续答入口，点进去落在没答完的那一题。
7. 按 F12 查看 Console 是否有红色错误；Network 中本地脚本、样式和图片无 404。用设备模拟检查 390×844 的窄屏是否可滚动、刻度、选项和结局图是否被截断。
8. 作者链接共两处：首页脚注下面一行、档案页页脚。两处文案都是「关注作者 · miracle-mile」，都在新标签打开 `https://space.bilibili.com/288422918`，键盘 Tab 能聚焦、有可见焦点框，减少动态与低刺激下照常显示；首页那行在开始按钮下面，不挡按钮。结尾黑场里不再放链接。

## 部署与文件

无需构建。发布时一并部署 index.html、questions.js、audio.js、horror.js、effects.css 和整个 assets 目录；不要只上传 HTML。资源使用相对路径，兼容 GitHub Pages 子目录。

GitHub Pages 可继续使用仓库已有部署设置；推送功能分支不会自动将修改合并到主分支。

- index.html：页面、问卷流程和结局内容。
- questions.js：题库和纯计分逻辑（五级量表、连续分、两本账、平持指纹）。
- audio.js：本地音效合成及生命周期。
- assets/audio/：本地恐怖环境音与突发音采样、作者及授权记录；发布时需要一并上传。
- tools/prepare-audio.py：从官方原始压缩包重建两份采样（可选开发工具，网页运行无需 Python）。
- horror.js、effects.css：随机事件和结局图样式。
- assets/endings.webp：16 格结局图集。
- `assets/reveal-*.webp` 存放结尾的三帧表情肖像。
- `tests/` 存放题库、计分、分布、答题流程、音频与结尾演出的回归测试。
- tools/simulate.js：分布模拟脚本。
