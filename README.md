# HTTI · 虚界投影

静态恐怖互动问卷：32 道五级量表题、4 段对话、两本独立的账与 16 种结局配图。用于娱乐，不是经过验证的心理测量工具。

## 本地预览

在项目目录打开 PowerShell：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

保持终端运行，浏览器打开 http://127.0.0.1:8765/ 。若 python 不可用，改用 py。按 Ctrl+C 停止服务。若端口已占用，先尝试直接打开页面，或将端口改为 8766。

也可以直接双击 index.html 用 file:// 打开：页面没有 fetch、没有 ES module、没有 Worker，脚本都是普通 `<script>`，图集和音频都走相对路径，所以本地文件直接打开也能玩。进度存储失败时自动降级（不续答，其余照常）。起 http 只是为了绕开个别浏览器对 file:// 的额外限制（例如极少数版本的自动播放策略），不是必需。

## 本次改进

- 题目从「四选一」改成「一句陈述 + 五级量表」：完全不符合 / 比较不符合 / 不确定 / 比较符合 / 完全符合，记 0–4 分。每维 8 题，正问与反向题各 4 道，反向题按 4−档位翻转；代码里用 `dir` 标着，改题时不会漏。
- 计分改成连续分：每维 0–32，`ratio = 分 / 32`，大于 16 落开极，小于 16 落闭极。恰好 16 分的平持不再默认归闭极，改由作答指纹（按题目 ID 排序后的答案串算 FNV-1a）决定，结果页照实以「≈ 持平」和虚线标出，不隐藏。全选同一档时四维恒为 16 分，落在码表里五个互相不同的码，不会靠一档到底拿到最开或最闭的那一型；结果页照常出档案，不为这份答案加任何标注或提示，类型名、配图、复制文本都只写结果本身。
- 两本账拆开：里层 = 四扇门（门/频/权/痕）的平均开放度；表层只看「不会被吓到、不入戏、不留痕」三项，不含门。所以两账不再共用同一个 O，相加也不是固定值——只有门开是 125，只有频率开是 92，随机作答落在 86–115 之间（均值 100）。
- 默认开启环境音，首次点击继续后启动；声音由 Web Audio 本地合成，包括低频、失谐泛音、耳语、敲击和心跳。M 键或顶部按钮静音；页面进入后台时暂停。浏览器不支持音频时可继续答题。
- 恐怖事件分两类：**「那一次」突脸**每轮只有一次——第 11 题（qi>=10）起从后面的题里随机指定一道，那道题一进入就立刻触发（0 延迟；只有恰好落在黑屏段才用黑场），不吃冷却、不设次数上限；**氛围事件**（阴影 / 敲击 / 耳语）仍是原来的随机逻辑：第 11 题起、间隔 ≥3 题、≥16 秒、每轮最多 5 次，池子里没有突脸和黑场。切题或离开页面会收掉排队中的氛围事件，已经指定的那一次突脸不会丢。
- 恐怖层原样保留 Together017 版：突脸用的是结局图集第一格（`assets/endings.webp` 的 `0 0 / 400% 400%`），16 型配图按类型表顺序取格，一套图两用。
- 提供低刺激模式和突发效果开关；尊重系统减少动态效果偏好——但**减少动态不是删掉突脸**，见下表。
- 左下角是对讲机通联记录（`CH-07 / 救援频道`）：一支探险小队进入 B2 层遭遇「她」，9 条记录随答题进度逐条解锁，从例行报到一路掉到只剩电流。每条按 40–60ms 一个字打出来（后面还排着行时提速到 30ms，不拖住换题节奏），打完停 0.6 秒再接下一行；减少动态或低刺激下整行直接写好，不做逐字。恐怖事件落下时对讲机里会多一行 `[noise]` 杂音、面板抖一下；低刺激与减少动态下不插杂音也不抖。面板本身对读屏隐藏（`aria-hidden`），只有最后一条「只剩电流」单独播报一次。浅色阶段整块隐藏，不抢戏。
- 结尾演出接在「找到你了」之后、结果档案之前，总共约 5.3 秒：**突然咧嘴露牙**（0.25 秒内硬切——嘴部从一条缝一次性裂开，露出上下两排牙，牙缝用细竖线分隔、边缘略不齐，眼睛同步睁大一点并保留发光；配一记短促的低频冲击）→ 停留约 0.65 秒后立刻进撕裂（RGB 通道分离 + 横向切片错位 + 三次黑场快闪 + 扫描线抖动，1.4 秒，强度高于随机事件）→ 黑场文字「欢迎加入我们」（3 秒）→ 才展开结果档案。这一段不再有缓慢描线和拖长音。减少动态下三段都在，只是换成静止露牙帧、一次静止闪帧和一行预告。这段演出与 `horror.js` 的随机事件完全独立，不共用冷却。

### 恐怖事件在三种偏好下的表现

| 场景 | 突脸 / 黑场 | 声音 | 说明 |
|---|---|---|---|
| 默认 | 那一次突脸：face 650ms、黑场 950ms（仅当指定题落在黑屏段）；氛围事件 1600ms | 有 | 每轮一次突脸，进入指定题立刻出现；氛围事件仍受 16 秒 + 3 题 + 每轮 5 次限制 |
| 系统「减少动态效果」 | **仍然会出现**，改成可预期形式：先 1.6 秒文字预告，再一张不缩放、不闪的静止画面（突脸 1500ms、黑场 1700ms） | 有 | 覆盖 CSS 里原有的「减少动态就隐藏突脸」，改由 horror.js 驱动预告与静止帧 |
| 用户主动关掉突发效果 / 低刺激模式 | 关闭（用户自己的选择，默认是开着的） | 关 | 顶部按钮随时可开回来 |

闪烁层（第 5 阶段）在两处都仍然关闭；减少动态下不再有横扫阴影和缩放动画，但画面本身不会缺席。
- 16 种结局各有一幅生成插画，使用本地 WebP 图集。具体分数影响明暗、对比度和侵蚀层。
- 结果编号作为纯文本显示（四位随机数 0000–9999，结果生成时抽一次），不上传；「找到你了」显示「型名-编号1234」，档案页宿主行与复制文本同步用这个编号。开局不再要求输入名字或 ID，开始按钮固定为小写 `sink`，永远可用。支持 1–5 数字键答题、← 返回上一题、复制结果和重新测试。
- 进度存在 sessionStorage 里（键名 `htti.session.v1`）：同一个会话里刷新或误关标签页再回来，首页会问要不要接着上次那一题。只覆盖本次会话，不做跨天续答，关掉浏览器就不保留；黑屏期间锁住答题，漏答的题会被送回原题而不是按 0 分算。
- 顺手修的无障碍问题：小字提到 10–11px 一档、低对比色压深、所有屏可聚焦、警告弹窗有焦点陷阱和 Esc、「她在线」在窄屏不再整块消失（改成底部单行）、结果出现时向读屏播报。

更多情境旨在改善区分度。10 万次随机作答下 16 型各占 6.17%–6.34%（见下），但真实玩家分布仍需后续采样验证。

## 浏览器人工验收

1. 打开首页，确认默认音效选项勾选；点击继续后播放环境音。关闭、开启及 M 键切换有效。
2. 首页确认没有名字/ID 输入，开始按钮固定为小写 `sink`、直接可用；每道正式题是一句陈述加五个刻度，鼠标和 1–5 数字键都能选，快速连点只记一次，返回后能看到原来选的那一档。
3. 完成 32 题及 4 段对话，确认前期较轻、后期逐步加深。后期每题可停留 8–10 秒观察随机事件，单轮没有遇到某种事件属正常。
4. 答题过程中切到其它标签页，确认暂停声音；返回后恢复。关闭突发效果后不再随机突脸。第 6 题后的黑屏期间试着按数字键，应该完全没反应。
5. 完成结局揭示，确认图片显示、名称与类型匹配、两个分数及四维条形图正常（持平的维度是虚线和「≈」），复制结果可用。
6. 点「再测一次」确认进度归零；中途关掉标签页再打开，确认首页出现续答入口，点进去落在没答完的那一题。
7. 按 F12 查看 Console 是否有红色错误；Network 中本地脚本、样式和图片无 404。用设备模拟检查 390×844 的窄屏是否可滚动、刻度、选项和结局图是否被截断。
8. 作者链接共两处：首页脚注下面一行、档案页页脚。两处文案都是「关注作者 · miracle-mile」，都在新标签打开 `https://space.bilibili.com/288422918`，键盘 Tab 能聚焦、有可见焦点框，减少动态与低刺激下照常显示；首页那行在开始按钮下面，不挡按钮。结尾黑场里不再放链接。

## 部署与文件

无需构建。发布时一并部署 index.html、questions.js、audio.js、horror.js、effects.css 和 assets/endings.webp；不要只上传 HTML。资源使用相对路径，兼容 GitHub Pages 子目录。

GitHub Pages 可继续使用仓库已有部署设置；推送功能分支不会自动将修改合并到主分支。

- index.html：页面、问卷流程和结局内容。
- questions.js：题库和纯计分逻辑（五级量表、连续分、两本账、平持指纹）。
- audio.js：本地音效合成及生命周期。
- horror.js、effects.css：随机事件和结局图样式。
- assets/endings.webp：16 格结局图集。
- tests/：Node.js 回归测试（42 项：题库与计分、分布、页面流程、音频、随机事件，以及对讲记录与结尾演出（露牙硬切、顺序、时长））。
- tools/simulate.js：分布模拟脚本。

本次修改仍需在本机真实浏览器中验收画面和声音。自动测试通过不代表已完成人工试听。
